快速开始

1. 启动服务器

cargo run -- http --addr 0.0.0.0:3000 --admin-token your-secret

2. 连接管理后台

在页面顶部输入服务器地址和 Admin Token，点击"连接"。

3. 创建 API Key

点击"创建 Key"按钮，填写名称和用户 ID，创建后会显示 API Key。

4. 使用 API Key

curl -X POST http://your-server/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Authorization: Bearer amcp_your_api_key" \
  -H "X-Poke-User-Id: your-user-id" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{...}}'

5. GitHub 登录与访问控制

登录仅支持 GitHub。在 GitHub 白名单 页维护允许登录的用户（按用户名或 UID），白名单为空时所有 GitHub 用户可登录。

自定义 Headers

以 X-Poke- 或 X-Custom- 开头的 Header 会自动记录到日志中。
